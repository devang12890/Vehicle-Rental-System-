# Vehicle Rental System 🚗

A simple console-based Vehicle Rental System developed using Core Java and Object-Oriented Programming concepts.

## 📌 Project Overview

This project allows users to:

* View available vehicles
* Rent a vehicle
* Return a vehicle
* Calculate rental cost

The project was created to strengthen Core Java and OOPs concepts through a real-world mini application.

---

## 🚀 Technologies Used

* Core Java
* Object-Oriented Programming (OOPs)
* Console-Based Application

---

## 🧠 OOP Concepts Used

* Encapsulation
* Inheritance
* Polymorphism
* Abstraction
* Method Overriding
* Constructors

---

## ⚙️ Features

* Show available vehicles
* Rent vehicles
* Return rented vehicles
* Calculate total rent
* Menu-driven console interface
